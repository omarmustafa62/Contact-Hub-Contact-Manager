# Contact Hub — Contact Manager

A browser-based contact management application built with vanilla JavaScript. Users can organize contacts, update records, search the list, and mark important contacts for quick access.

## Highlights
- Add, edit, and delete contacts
- Search contacts
- Mark contacts as favorites
- Mark emergency contacts
- Contact counters and filtered contact views
- Browser persistence with localStorage
- Avatar initials and generated color styling

## Built With
- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- Browser localStorage

## Run Locally
Clone the repository, then open `Contact-Hub-Contact-Manager/index.html` in a browser.

## Project Structure
- `Contact-Hub-Contact-Manager/index.html` — page markup
- `Contact-Hub-Contact-Manager/styles/` — Bootstrap, custom, and responsive styles
- `Contact-Hub-Contact-Manager/js/main.js` — contact management logic
- `Contact-Hub-Contact-Manager/Images/` — image assets
- `Contact-Hub-Contact-Manager/assets/fonts/` — local font files
- `Contact-Hub-Contact-Manager/webfonts/` — icon fonts

> Contact data is stored in the browser using localStorage; there is no remote database or account synchronization.
