# Contact Hub – Contact Manager

A contact-management web interface for organizing personal contacts in one place.

## Features
- Contact overview with total, favorite, and emergency counts
- Search interface for finding contacts
- Add-contact form/modal
- Contact organization UI
- Responsive layout

## Built With
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Run Locally
1. Clone this repository.
2. Open `Contact-Hub-Contact-Manager/index.html` in your browser.

## Project Structure
The website source is inside `Contact-Hub-Contact-Manager/`, with images, stylesheets, scripts, and fonts stored in separate directories.
